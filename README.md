# Portfolio Website

A modern, animated portfolio website showcasing my work as a Software Developer with expertise in React and Unity development.

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

## Application Preview

A sleek, one-page portfolio featuring:

- Interactive hero section with animated background
- Skills showcase with technology highlights
- Work experience and project portfolio
- Downloadable CV and contact information

## Technologies Used

This project utilizes the following technologies:

- **Framework/Library**: React
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/UI & Lucide Icons
- **Animations**: Motion/Framer Motion
- **Icons**: DevIcons & Lucide React
